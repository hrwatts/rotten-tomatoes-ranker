# Sample Data

These files are small illustrative samples that show the output schema and ranking format.

They are not intended to represent full coverage or authoritative rankings.

## Generation Environment

These sample files were produced with:

- Python 3.10.2
- playwright==1.53.0
- Playwright bundled Chromium for 1.53.0 (installed via `playwright install chromium`)
- requests==2.32.3
- beautifulsoup4==4.12.3
- lxml==5.3.0
